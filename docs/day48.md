# Day48 — 分析画面の改善とβ公開に向けた検証

2026年11月16日。プライベートβで実際に操作し、表示の読みやすさ、目的の情報への移動、AIに渡す動画の選択を改善しました。

## 1. 時系列グラフの読みやすさ

記録が増えると、横軸の時刻と各点の数値が重なり、変化を読み取りにくくなっていました。

- 視聴者数・フォロワー数のグラフを共通コンポーネントに整理
- 画面幅に応じて時刻ラベルを間引き、横軸には実際の時間間隔を反映
- データ点と線を細くし、全点への常時数値表示をやめて選択した記録の日時・人数を表示
- 人数の縦軸、キーボードでの記録選択、小さい画面での表示を整備

見た目を簡潔にしつつ、元の観測点を削らず確認できる形にしました。

## 2. 長い分析ページの移動

実績、履歴、推移グラフ、AIの提案などが縦に並び、目的の項目までスクロールする負担がありました。

- 16項目へ移動できる目次を上部に追従表示
- PCでは配信実績・視聴者グラフ・フォロワーグラフへの直接リンクを設置
- スマートフォンでも開ける折りたたみメニューを採用
- 移動先の見出しが目次に隠れない余白と、キーボード操作を考慮
- 操作確認のフィードバックを受け、開閉矢印を大きく太いSVGと背景付きの表示に変更

## 3. 動画をAI分析の対象から外す設定

連携チャンネルには、活動分析に使いたい動画以外にテスト・手順説明などの動画が含まれることがあります。取得できる動画を一律に分析するだけでは、相談の目的に合わない入力が混ざるため、利用者が選べるようにしました。

- 動画一覧から「分析から除外」「分析に戻す」を切り替え
- 選択をアカウント単位で保存
- 次のAI相談・YouTube分析では、サーバー側で対象動画を除外
- AI相談に渡す動画別ランキングとグラフにも同じ除外設定を適用
- 保存・読込エラーを表示し、設定を確認できない状態で動画分析を進めない設計

動画そのものは削除しません。過去のAI回答やYouTubeが返すチャンネル全体の集計値も書き換えません。動画別の分析対象とチャンネル全体の指標を区別して説明します。

## 4. 検証と公開準備

- 認証メールの到達、YouTube・Twitch連携後のデータ表示、AI相談の応答を操作確認
- OAuthのブランディング確認とデータアクセス審査申請を実施。データアクセス審査は承認待ち
- グラフは複数の表示幅と、単一点・一定値・複数点の描画を確認
- 動画除外は、除外・復帰・全件除外、入力検証、本人IDによる設定操作、認証・Origin制御、失敗時の扱い、AI入力・グラフの対象をモックテストで確認
- 変更対象のLint・本番ビルド、およびデプロイ後の更新コード配信を確認
- 実アカウントで動画除外設定の保存成功を確認

再読み込み後の設定維持と、実際の次のAI回答への反映は引き続き確認予定です。登録・認証・利用者間のデータ分離・退会削除・利用制限などの公開前E2E確認も残っており、この記録は一般公開準備の完了を示すものではありません。
